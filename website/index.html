Secure Cloud File Storage

Encrypted File Blocks, Amazon S3 and CloudFront CDN

Project Overview

This project provides a secure approach to cloud file storage by dividing files into smaller blocks, encrypting them, and storing them in Amazon S3.

Objectives

  • Divide files into smaller blocks.
  • Encrypt blocks using AES-GCM before cloud upload.
  • Store encrypted blocks in Amazon S3.
  • Download, decrypt, and reconstruct the original file.
  • Use CloudFront CDN with HTTPS for website delivery.

Technologies Used

  • Python and Flask
  • Amazon S3
  • AES-GCM encryption
  • AWS CloudFront
  • HTML and CSS

System Workflow

Select File → Divide into Blocks → Encrypt Blocks → Upload to Amazon S3 → Download Encrypted Blocks → Decrypt → Reconstruct Original File.

Security Features

  • Encryption before uploading files to cloud storage.
  • Private Amazon S3 storage.
  • HTTPS delivery for the documentation website through CloudFront.
